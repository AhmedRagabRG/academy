# Accessibility Validation Checklist: Application Foundation

- [x] Keyboard-only login and workspace navigation complete without traps
- [x] Visible focus and logical focus order verified
- [x] Tablet drawer contains focus and returns focus on close
- [x] Screen reader semantics expose Arabic page titles, errors, progress, and route changes
- [x] Light and dark theme contrast reviewed
- [x] Arabic mixed with email addresses and numbers uses bidi isolation
- [x] Layout remains usable at 200 percent zoom
- [x] Reduced-motion preference suppresses non-essential animation
- [x] Desktop, laptop, and tablet layouts have no hidden required action
- [x] Automated axe checks report zero critical or serious violations
