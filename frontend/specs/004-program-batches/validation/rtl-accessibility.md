# RTL and Accessibility Validation

- Arabic RTL is inherited from the root and all codes, dates, numbers, and money use LTR/bidi isolation.
- Forms use fieldsets, legends, labels, error alerts, keyboard controls, and text-based status/capacity indicators.
- Axe checks pass with zero serious or critical findings on list, detail, and edit routes.
- Confirmation dialogs expose dialog semantics, autofocus, cancel, pending, and focus-safe native controls.
